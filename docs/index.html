What the tier means, in images

The composition is right in all three of these. That is the trap — a result can be geometrically perfect and still not be what was asked for.

Reproducing any of this

Two runs with the same seed, strength, prompt and input bytes returned images that differed on 0 of 1,048,576 pixels. If a re-run comes back different, the input changed. The usual culprit is a re-encode: feeding a lossy WebP copy of a PNG that an edit was originally made from moved the result by 17.0/255 mean per-pixel — the composition, palette and medium all returned, the brush texture did not. Keep the original file if you intend to re-run. Recording the seed is not enough for image-to-image; the seed and the exact input bytes together are what reproduce a generation.
